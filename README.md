# حكايتنا | LoveStory Maker 💖

موقع رومانسي ساحر تم تصميمه بكل حب وإتقان بواسطة **HTML, CSS, JavaScript**، مخصص ليجمع صورك وصور حبيبتك بضغطة زر واحدة على **Extract** ليتحول إلى تجربة رومانسية أسطورية تخطف قلبها وعقلها.

---

## ✨ المميزات الأسطورية للمشروع:

1. **شاشة إعداد ساحرة (Creator Studio)**:
   - تصميم زجاجي عصري وفاخر (Glassmorphism) مع ألوان دافئة وناعمة.
   - إدخال اسمك واسم حبيبتك ولقبكم الخاص أو كلمة سر بينكم.
   - تحديد تاريخ أول لقاء أو بداية حكايتكم لحساب **عداد حب مباشر**.
   - رفع صور الشاب وصور البنت وصور الذكريات المشتركة بكل سهولة (سحب وإفلات أو اختيار من الجهاز مع معاينة وإمكانية حذف الصور).
   - اختيار رسالة حب من نماذج جاهزة تذوّب القلب بضغطة زر أو كتابة رسالتك الخاصة.
   - اختيار ثيم الموقع (الوردي الرومانسي، الليالي البنفسجية الساحرة، الذهبي الملكي، أزهار الكرز).
   - زر **تجربة فورية بنموذج رومانسي وصور تجريبية** لمعاينة النتيجة بضغطة زر قبل الرفع!

2. **الموقع الرومانسي المُستخرج (The Romantic Experience)**:
   - **واجهة العشاق (Hero Section)**: أسمائكم مع علامة اللانهاية والقلب النابض `∞` وجمل عشق مؤثرة.
   - **عداد الحب التفاعلي (Live Love Counter)**: يحسب بالأيام والساعات والدقائق والثواني بدقة، وينبض كل ثانية مع عبارة حب خالدة.
   - **بطاقتي العشاق (Soulmates Cards)**: بطاقة ثلاثية الأبعاد لفارس قلبها وبطاقة لأميرة قلبه مع صور كل منكما ومصغرات تفاعلية للتنقل بين الصور.
   - **معرض صور بولارويد (Polaroid Memories Gallery)**: صوركم بتأثير كاميرا البولارويد الواقعية، مع شريط لاصق لطيف، واقتباسات غرامية لكل صورة، ومودال تكبير (Lightbox) عند النقر.
   - **مظروف الحب السحري ثلاثي الأبعاد (3D Love Letter Envelope)**: مظروف أحمر مختوم بقلب ذهبي؛ عندما تضغط عليه حبيبك ينفتح بشكل ثلاثي أبعاد واقعي ويخرج الجواب الورقي بكلماتك المعبرة بخط عربي شاعري!
   - **بطاقات "ليه قلبي اختارك؟" (Why I Love You Deck)**: لعبة تفاعلية لطيفة؛ كل ضغطة تظهر سبباً شاعرياً جديداً من أسباب عشقك لها مصحوبة بنغمة قيثارة هادئة.
   - **خلفية كانفاس تفاعلية (Interactive Canvas Particles)**: قلوب طافية وبتلات ورود وردية ونجوم لامعة تتبع حركة الماوس أو اللمس.
   - **محرك صوتي متكامل (Romantic Audio Engine)**: عزف بيانو رومانسي هادئ تلقائي تم تصنيعه عبر Web Audio API (لا يحتاج ملفات خارجية)، مع إمكانية رفع مقطع صوتي مخصص (MP3)، وشريط تحكم صوتي تفاعلي بموجات راقصة.
   - **هدية فورية (Export Standalone Website)**: إمكانية تحميل الموقع كاملاً بضغطة زر كملف مستقل واحد بصيغة HTML يحتوي على كافة الصور والتصميم، لترسله لها كهدية على واتساب أو تليجرام لفتحه حتى بدون إنترنت!

---

## 🚀 طريقة التشغيل السريعة:

1. اضغط مرتين على ملف `index.html` في هذا المجلد ليفتح في أي متصفح (Chrome, Edge, Safari, Firefox).
2. أو من خلال الطرفية (Terminal):
   ```bash
   python -m http.server 8000
   ```
   ثم افتح الرابط: `http://localhost:8000` في متصفحك.

## 🎁 كيف ترسل الموقع لحبيبتك كهدية مفاجأة؟

- **الطريقة الأولى (الأسهل والأسرع)**:
  بعد الضغط على **Extract** في الموقع، اضغط على زر **"تحميل الموقع هدية 🎁"** الموجود في أسفل الصفحة أو في الشريط العائم. سيتم تنزيل ملف باسم `حكايتنا_[اسمك]_و_[اسمها].html`، يمكنك إرسال هذا الملف مباشرة إليها على واتساب أو تيليجرام وستفتحه مباشرة على هاتفها أو حاسوبها بكامل جماله!

- **الطريقة الثانية (رابط دائم مجاني أونلاين)**:
  يمكنك رفع ملفات المجلد على [Netlify Drop](https://app.netlify.com/drop) أو **GitHub Pages** وسيكون لديك رابط خاص مثل `https://our-story.netlify.app` ترسله لها كمفاجأة لا تُنسى في عيد ميلادها أو ذكرى لقائكم!

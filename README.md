# حكايتنا | Love & Friends Story Maker 💖👊

موقع تفاعلي ساحر وفخم تم تصميمه بكل إتقان بواسطة **HTML, CSS, JavaScript**، مخصص ليجمع صورك وصور حبيبتك أو صاحبك وأخوك، وبضغطة زر واحدة على **Extract** يتحول إلى تجربة أسطورية تخطف القلب.

المشروع مرفوع ويعمل مباشرة على GitHub Pages:
🔗 **الرابط المباشر على النت**: [https://medo-adel.github.io/Love/](https://medo-adel.github.io/Love/)

---

## ✨ المميزات الجديدة والتحديثات:

### 1. وضعين مختلفين (حب ورومانسية 💖 VS صحاب وجدعنة 👊):
- **حكاية حب ورومانسية**:
  - مخصص للبنات والأحباب (فارس قلبها وأميرة قلبه).
  - كلام غرام وشوق، وعهود للمستقبل، وامتنان لوجودها.
  - عداد حب مباشر بالثواني والأيام منذ بداية حكايتكم.
  - ثيمات وردية وسحرية وذهبية ناعمة.
- **صحاب وجدعنة وبيست فريند**:
  - مخصص للصحاب الجدعان وأخوات السنين.
  - كلام عِشرة ورجولة ومواقف وشريك الضحك والمصايب.
  - عداد عِشرة وصداقة يحسب سنين وأيام الأخوة.
  - ثيمات سيان عصرية (Cyber Cyan)، وزمردي وسند (Emerald Loyalty)، وغروب دافئ وذكريات (Sunset Friends).

### 2. إرسال الموقع كرابط أونلاين مباشر (Live Hosted Link):
- بضغطة واحدة على زر **"رابط أونلاين 🌐"** أو **"مشاركة كرابط مباشر"**، يقوم الموقع بتوليد رابط أونلاين مشفر يحتوي على كافة الأسماء والتواريخ والرسائل والثيم!
- يمكنك إرسال الرابط مباشرة عبر **واتساب** أو **تليجرام** أو نسخه بضغطة زر.
- عندما يفتح الطرف الآخر الرابط، يفتح الموقع فوراً على الواجهة الفخمة والموسيقى والعداد والمظروف السحري!

### 3. تحميل الموقع كهدية مستقلة (Offline Gift File 🎁):
- يمكنك أيضاً تحميل الموقع بالكامل كملف `HTML` مستقل يعمل على أي هاتف أو كمبيوتر بدون إنترنت وبكامل الصور والتأثيرات!

## 🛠 تفعيل GitHub Pages (خلال دقيقة واحدة):

1. افتح صفحة الـ Repo الخاص بك على GitHub:
   [https://github.com/medo-adel/Love](https://github.com/medo-adel/Love)
2. اضغط على **Settings** في الأعلى.
3. من القائمة الجانبية على اليسار، اضغط على **Pages**.
4. تحت **Build and deployment**:
   - في خانة **Source** اختار: **Deploy from a branch**.
   - تحت **Branch** اختار: `main` ومجلد `/ (root)` ثم اضغط **Save**.
   *(أو يمكنك اختيار **GitHub Actions** لأننا قمنا بإضافة workflow تلقائي جاهز!)*
5. خلال ثوانٍ معدودة، سيكون موقعك متاحاً للعالم كله على:
   👉 **https://medo-adel.github.io/Love/**
